📋 Conseils pour un message efficace

🐛 Pour un bug :

  • Décrivez les étapes pour reproduire le problème
  • Indiquez le comportement attendu vs observé
  • Ajoutez des captures d'écran si pertinent
  • Mentionnez votre système d'exploitation
  • Copiez les messages d'erreur exacts

❓ Pour une question :

  • Vérifiez d'abord la documentation
  • Consultez le guide d'utilisation
  • Recherchez dans les issues existantes
  • Soyez précis dans votre question

✨ Pour une suggestion :

  • Expliquez le problème que cela résoudrait
  • Décrivez la solution proposée
  • Mentionnez des alternatives considérées
  • Évaluez l'impact sur les utilisateurs existants
Temps de réponse : Nous nous efforçons de répondre dans les 48 heures ouvrables. Pour les bugs critiques, utilisez directement GitHub Issues.

Réponses rapides aux questions les plus courantes

🔧 Installation et configuration

MateZone ne démarre pas

Vérifiez que vous avez Java 11+ et MySQL installés. Consultez le guide de dépannage pour plus de détails.

Erreur de connexion à la base de données

Vérifiez votre fichier config.properties et que MySQL est démarré. Voir la section configuration.

Le client ne se connecte pas au serveur

Assurez-vous que le serveur est démarré et que le port (8080 par défaut) n'est pas bloqué par un firewall.

💻 Utilisation et fonctionnalités

Comment créer un nouveau canal ?

Une fois connecté, utilisez le bouton "Nouveau canal" ou le menu contextuel. Voir le guide des canaux.

Puis-je modifier ou supprimer mes messages ?

Actuellement, MateZone ne permet pas de modifier ou supprimer les messages après envoi. Cette fonctionnalité est en cours de développement.

Les messages sont-ils sauvegardés ?

Oui, tous les messages sont sauvegardés dans la base de données MySQL et l'historique est conservé.
