Messagerie instantanée

MateZone

Messagerie instantanée en Java

Une messagerie en temps réel développée en Java : WebSockets, architecture hexagonale et base MySQL. Un projet personnel à but non lucratif, mené à deux pour apprendre et tester de nouvelles technologies.

02

Fonctionnalités

Ce que MateZone sait faire aujourd'hui.

💬

Messagerie en temps réel

Les messages arrivent instantanément grâce aux WebSockets, sans rafraîchir ni interroger le serveur en boucle.

👥

Comptes et groupes

Inscription, connexion et profils avec image, groupes de discussion et conversations privées.

🔒

Mots de passe protégés

Les mots de passe ne sont jamais stockés en clair : seul leur hash est conservé dans la base de données.

🖥️

Interface native

Un client de bureau en Java Swing pour la version 1.0, et en JavaFX avec FXML dans la branche pre-releases-beta, la plus récente.

🗄️

Historique persistant

Messages, comptes et groupes sont enregistrés dans MySQL : l'historique se retrouve à chaque connexion.

🏗️

Architecture hexagonale

Le métier est isolé de l'interface, du réseau et de la base : le code reste testable et facile à faire évoluer.
