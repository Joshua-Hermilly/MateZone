04

Écrire un bon message

Pour un bug

  • Décrivez les étapes pour reproduire le problème
  • Indiquez le comportement attendu et celui observé
  • Mentionnez votre système et la version de MateZone
  • Copiez les messages d'erreur exacts

Pour une question ou une idée

  • Consultez d'abord le guide et la documentation
  • Cherchez dans les issues existantes
  • Expliquez le problème que votre idée résoudrait
