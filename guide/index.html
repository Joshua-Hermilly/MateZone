Installer et utiliser MateZone

De l'installation au premier message : prérequis, base de données, configuration, démarrage et exploitation.

01

Prérequis

Logiciels requis
LogicielVersionNotes
Java JDK11 ou supérieurDéveloppé avec le JDK 25
MySQL8.0 ou supérieurPour la persistance des données
GitDernière versionPour cloner le dépôt

Vérifiez vos installations avec java -version, mysql --version et git --version.

02

Installation

  1. Cloner le dépôt

  2. Créer la base de données

    Sécurité : utilisez un mot de passe fort pour l'utilisateur de la base et notez-le pour la configuration.

  3. Importer le schéma

  4. Configurer l'application

    Copiez config.properties.example vers config.properties, puis renseignez vos paramètres.

    Important : ne commitez jamais config.properties. Il est dans le .gitignore.

  5. Compiler le projet

    Si la compilation réussit, les fichiers .class apparaissent dans bin/.

03

Premiers pas

  1. Démarrer le serveur

    Si le port 8080 est déjà utilisé, changez-le dans config.properties.

  2. Lancer le client

    La fenêtre de connexion s'ouvre. Vous pouvez lancer plusieurs clients pour tester des conversations à plusieurs.

  3. Créer un compte puis se connecter

    Cliquez sur « S'inscrire », choisissez un pseudo unique et un mot de passe, puis connectez-vous. L'interface principale affiche la liste des groupes, l'historique des messages et la zone de saisie.

04

Utiliser la messagerie

Envoyer un message

  • Sélectionnez un groupe dans la liste
  • Saisissez votre message dans la zone de saisie
  • Cliquez sur « Envoyer »

Lire les messages

  • Les 50 derniers messages sont chargés avec l'historique
  • Chaque message affiche son auteur et sa date
  • Les nouveaux messages apparaissent sans rafraîchir

06

Dépannage

MateZone ne démarre pas

Vérifiez que Java 11 ou plus et MySQL sont installés, et que le serveur est lancé avant le client.

Erreur de connexion à la base de données

Vérifiez votre fichier config.properties (adresse, utilisateur, mot de passe) et que MySQL est démarré.

Le client ne se connecte pas au serveur

Assurez-vous que le serveur est démarré et que le port (8080 par défaut) n'est pas bloqué par un pare-feu.

Un autre problème ? Ouvrez une issue ou contactez-nous.
